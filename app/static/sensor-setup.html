Connect your room sensor

Use your existing Tuya Smart or Smart Life account. This connection works without the Tuya developer trial and does not require this computer to stay on.

In the app: Me → gear icon → Account and Security → User Code.

Checking connection…

Sensor reads pause while Smart Room is off. When on, refreshes are at least 40 seconds apart. Setup checks the sensor once. Connecting does not turn on Smart Room or change the heater.

The connection returns the latest reported values. Automatic temperature control stays paused if the measurement time cannot be verified.
